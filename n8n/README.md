# Orquestador: Flujos de n8n

Esta carpeta existe para versionar los flujos (workflows) de n8n.
El negocio no es la página web, sino el ecosistema autónomo. Por lo tanto, el "cerebro" debe estar versionado aquí.

## Tareas Pendientes para el Desarrollador:
1. Abre tu instancia local/remota de n8n.
2. Ve a tus workflows ("Triage IA", "Carrito Abandonado", "Transferencia Pendiente").
3. Selecciona 'Download' o 'Export'.
4. Guarda los archivos .json en esta carpeta.
5. Haz un commit y pushea al repositorio.
